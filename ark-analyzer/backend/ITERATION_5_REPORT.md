## 3. 发现的问题与修复

### 问题1：嵌套事务错误（核心Bug）

**问题描述**：
```
cannot start a transaction within a transaction
```

**根本原因**：
在 `update_single_file` 方法中，文件哈希计算、旧哈希查询等操作在事务内部执行，而aiosqlite不允许在已有事务的情况下再次执行 `BEGIN IMMEDIATE`。

**修复方案**：
调整代码执行顺序，将所有非数据库操作（哈希计算、文件读取、解析）移到事务开始之前：

```python
async def update_single_file(self, file_path: str, change_type: str = "modified") -> UpdateResult:
    # 1. 在事务外计算哈希
    new_hash = await FileHashCalculator.calculate_md5_async(file_path)
    old_hash = await self.db.get_file_hash(file_path)  # 这个查询也在事务外
    
    # 2. 在事务外读取和解析文件
    content = await self._read_file_safe(file_path)
    parsed_file = self.parser.parse_file(file_path, content)
    
    # 3. 只在事务内执行数据库操作
    async with self.db.transaction():
        existing_file = await self.db.get_file_by_path(file_path)
        if existing_file:
            await self._delete_file_relationships(existing_file['id'])
        entities = await self._insert_file_entities(file_path, new_hash, parsed_file)
```

**影响文件**：
- `synchronization_engine.py`

**修复状态**：✅ 已修复
