## 2. 发现的问题与修复

### 核心问题：嵌套事务错误（已修复）

**问题描述**: 在事务内部仍然有数据库查询操作，导致 `cannot start a transaction within a transaction` 错误。

**根本原因**: 在 `synchronization_engine.py` 的 `update_single_file` 方法中，虽然大部分查询已经移到事务外部，但仍然存在在事务内部调用 `get_file_by_path` 的情况。

**修复方案**: 将 `existing_file` 的查询完全移到事务外部：

```python
# 修复前（错误）
async with self.db.transaction():
    existing_file = await self.db.get_file_by_path(file_path)  # ❌ 在事务内查询
    if existing_file:
        await self._delete_file_relationships(existing_file['id'])

# 修复后（正确）
existing_file = await self.db.get_file_by_path(file_path)  # ✅ 在事务外查询
existing_file_id = existing_file['id'] if existing_file else None

async with self.db.transaction():
    if existing_file_id:
        await self._delete_file_relationships(existing_file_id)
```

**修改文件**: [synchronization_engine.py](file:///workspace/ark-analyzer/backend/src/services/synchronization_engine.py#L211-L224)
