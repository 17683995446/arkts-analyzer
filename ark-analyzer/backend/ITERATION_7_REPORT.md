## 2. 发现并修复的问题

### 问题 1: `extends_relations` 表缺失

**问题描述**:
在 `src/api/routes.py` 中，代码尝试访问 `extends_relations` 表，但该表在数据库初始化脚本中不存在。

**影响**:
- API 接口调用可能导致错误
- 代码与数据库结构不一致

**修复方案**:
在 `src/database/connection.py` 的 `_create_tables` 方法中添加了 `extends_relations` 表的创建语句：

```sql
CREATE TABLE IF NOT EXISTS extends_relations (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    parent INTEGER NOT NULL,
    child INTEGER NOT NULL,
    FOREIGN KEY (parent) REFERENCES classes(id) ON DELETE CASCADE,
    FOREIGN KEY (child) REFERENCES classes(id) ON DELETE CASCADE
);

CREATE INDEX IF NOT EXISTS idx_extends_parent ON extends_relations(parent);
CREATE INDEX IF NOT EXISTS idx_extends_child ON extends_relations(child);
```

**修改文件**: [connection.py](file:///workspace/ark-analyzer/backend/src/database/connection.py)
**修复状态**: ✅ 已修复
