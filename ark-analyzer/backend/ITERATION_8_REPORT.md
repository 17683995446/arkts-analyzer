## 6. 设计的缓存策略

### 6.1 FileHashCache - 文件哈希缓存

```python
class FileHashCache:
    """文件哈希缓存 - 避免重复计算"""
    
    def __init__(self, max_size: int = 2000):
        self._cache: Dict[str, str] = {}
        self._max_size = max_size
        self._stats = CacheStats()
    
    def get(self, file_path: str, mtime: float) -> Optional[str]:
        """获取缓存的哈希值"""
        key = f"{file_path}:{mtime}"
        if key in self._cache:
            self._stats.hits += 1
            return self._cache[key]
        self._stats.misses += 1
        return None
    
    def set(self, file_path: str, mtime: float, file_hash: str):
        """设置哈希值到缓存"""
        if len(self._cache) >= self._max_size:
            # FIFO淘汰
            oldest_key = next(iter(self._cache))
            del self._cache[oldest_key]
        key = f"{file_path}:{mtime}"
        self._cache[key] = file_hash
```

**预期效果**:
- 相同文件的重复处理速度提升 80%+
- 减少CPU的哈希计算负担
- 节省 30%+ 的处理时间

### 6.2 QueryCache - 数据库查询缓存

```python
class QueryCache:
    """数据库查询缓存"""
    
    def __init__(self, max_size: int = 1000, ttl: int = 60):
        self._cache: Dict[str, tuple] = {}
        self._timestamps: Dict[str, float] = {}
        self._max_size = max_size
        self._ttl = ttl  # Time-To-Live: 60秒
    
    def get(self, sql: str, params: tuple) -> Optional[Any]:
        """获取缓存的查询结果"""
        key = self._make_key(sql, params)
        if key in self._cache:
            if time.time() - self._timestamps[key] < self._ttl:
                self._stats.hits += 1
                return self._cache[key]
        return None
    
    def set(self, sql: str, params: tuple, result: Any):
        """设置查询结果到缓存"""
        if len(self._cache) >= self._max_size:
            # 删除最老的
            oldest_key = min(self._timestamps, key=self._timestamps.get)
            del self._cache[oldest_key]
            del self._timestamps[oldest_key]
        key = self._make_key(sql, params)
        self._cache[key] = result
        self._timestamps[key] = time.time()
```

**预期效果**:
- 统计查询速度提升 90%+
- 减少数据库往返次数
- 节省 50%+ 的数据库查询时间

### 6.3 缓存统计类

```python
@dataclass
class CacheStats:
    """缓存统计"""
    hits: int = 0
    misses: int = 0
    evictions: int = 0
    
    @property
    def hit_rate(self) -> float:
        total = self.hits + self.misses
        return (self.hits / total * 100) if total > 0 else 0
```
