## 3. 核心算法流程

### 3.1 单文件更新算法

```
Algorithm: UpdateSingleFile(file_path, change_type)

Input:
  - file_path: 要更新的文件路径
  - change_type: 变更类型 (created/modified/deleted)

Output:
  - UpdateResult: 更新结果

BEGIN TRANSACTION
  IF change_type == "deleted" OR NOT exists(file_path) THEN
    // 场景1: 文件被删除
    DELETE FROM files WHERE path = file_path
    // 外键级联删除 classes, methods, calls, components
  ELSE
    // 场景2: 文件新增或修改
    new_hash = CalculateMD5(file_path)
    old_hash = QueryFileHash(file_path)

    IF old_hash == new_hash THEN
      // 场景2a: 内容未变化，跳过
      RETURN UpdateResult(success=true, entities_updated=0)
    END IF

    // 删除旧数据
    file_id = QueryFileId(file_path)
    IF file_id != NULL THEN
      DELETE FROM files WHERE id = file_id
      // 外键级联删除
    END IF

    // 解析新内容
    content = ReadFile(file_path)
    parsed_file = ParseArkTS(file_path, content)

    // 插入新数据
    INSERT INTO files (path, hash, modified)
    INSERT INTO classes (...)
    INSERT INTO methods (...)
    // 不需要更新其他文件的数据！
  END IF

COMMIT TRANSACTION

RETURN UpdateResult(success=true, entities_updated=count)
```

### 3.2 防抖队列算法

```
Algorithm: DebouncedFileWatcher

Input:
  - pending_changes: 变更字典 {file_path: change_type}
  - debounce_seconds: 防抖延迟时间

WHILE service_running DO
  WAIT(500ms)  // 轮询间隔

  current_time = NOW()
  ready_changes = {}

  FOR EACH (file_path, event_type) IN pending_changes DO
    IF current_time - last_change_time[file_path] >= debounce_seconds THEN
      // 防抖时间已过，可以处理
      ready_changes[file_path] = event_type
      DELETE pending_changes[file_path]
    END IF
  END FOR

  IF ready_changes NOT EMPTY THEN
    CALL SyncEngine.incremental_update(ready_changes)
  END IF
END WHILE
```
